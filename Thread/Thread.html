Practice Problems: Java Threading Concepts

Level 1 : Basics (Creating Threads)
  1. Create a thread by extending the Thread class and print numbers from 1 to 10.
  2. Create a thread using the Runnable interface and display "Hello Thread" 5 times.
  3. Create two threads that print even and odd numbers separately.
  4. Create a thread that displays the current time every second for 10 seconds.
  5. Create a thread that prints the multiplication table of a given number.
  6. Create three threads representing different students submitting assignments.
  7. Create a thread that prints alphabets (A–Z) with a delay of 500ms.
  8. Create a thread that calculates the sum of numbers from 1 to 100.
  9. Create two threads displaying different messages simultaneously.
  10. Create a thread that simulates a loading bar using sleep().
Level 2 : Thread Methods
  1. Demonstrate the use of sleep() method.
  2. Demonstrate the use of join() method using two threads.
  3. Demonstrate the use of yield() method.
  4. Display thread information using getName(), getId(), and isAlive().
  5. Change thread names using setName().
  6. Create a program to check thread priorities (MIN_PRIORITY, NORM_PRIORITY, MAX_PRIORITY).
  7. Use interrupt() to stop a sleeping thread.
  8. Create a timer thread that runs for 20 seconds.
  9. Demonstrate daemon threads using setDaemon(true).
  10. Create a countdown thread using sleep() and join().
Level 3 : Synchronization
  1. Create two threads withdrawing money from the same bank account using synchronization.
  2. Implement synchronized methods in a counter class.
  3. Demonstrate race conditions without synchronization.
  4. Solve race conditions using synchronized blocks.
  5. Create multiple threads printing synchronized messages.
  6. Implement producer-consumer synchronization using wait() and notify().
  7. Create a ticket booking system using synchronization.
  8. Create a synchronized printer shared by multiple users.
  9. Implement synchronized deposit and withdrawal methods in a BankAccount class.
  10. Create a synchronized online shopping cart.
Level 4 : Inter-Thread Communication
  1. Implement Producer-Consumer problem using wait() and notify().
  2. Create two threads where one waits for user input and another processes it.
  3. Implement a thread-safe message box.
  4. Simulate a traffic signal system using wait() and notify().
  5. Create a thread communication program using notifyAll().
  6. Implement a classroom attendance system using inter-thread communication.
  7. Create a restaurant order management system using threads.
  8. Implement a bounded buffer problem.
  9. Create a thread that waits until another thread completes a calculation.
  10. Implement multiple consumers accessing a shared resource.
Level 5 : Thread Pool & Executors
  1. Create a fixed thread pool using ExecutorService.
  2. Execute 10 tasks using a thread pool of size 3.
  3. Demonstrate shutdown() and shutdownNow().
  4. Create a cached thread pool and execute multiple tasks.
  5. Create a scheduled thread pool that executes tasks periodically.
  6. Implement a file downloader using thread pools.
  7. Simulate a food delivery system using ExecutorService.
  8. Create a calculator service that handles multiple requests simultaneously.
  9. Compare thread creation with thread pool performance.
  10. Create a mini task scheduler using ScheduledExecutorService.
Level 6 : Advanced Threading Concepts
  1. Implement the Dining Philosophers problem.
  2. Solve the Readers-Writers problem.
  3. Create a Deadlock scenario using two shared resources.
  4. Solve the Deadlock problem using proper lock ordering.
  5. Implement ReentrantLock in a banking application.
  6. Demonstrate the use of Semaphore for resource management.
  7. Implement CountDownLatch for thread synchronization.
  8. Create a multiplayer game lobby simulation using CyclicBarrier.
  9. Implement AtomicInteger for thread-safe counting.
  10. Compare synchronized methods with ReentrantLock.

  4. Traffic Signal Management System.
  5. File Download Manager using Thread Pool.
