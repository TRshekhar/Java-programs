Practice Problems: OOPs Concepts

Level 1: Basics (Classes & Objects)
  1. Create a Student class with attributes (name, rollNo, marks) and display details.
  2. Create a Car class with brand, model, and price. Print details using a method.
  3. Create a Rectangle class to calculate area and perimeter.
  4. Create a Circle class to calculate area and circumference.
  5. Create a Book class with title, author, and price. Print book info.
  6. Create a Laptop class with RAM, processor, and price.
  7. Create a Employee class and calculate yearly salary.
  8. Create a Mobile class and display its features.
  9. Create a class BankAccount with balance and deposit method.
  10. Create a Person class and display details using constructor.

Level 2: Constructors & Methods
  1. Create a class with default and parameterized constructors.
  2. Implement constructor overloading in a Box class.
  3. Create a Student class with a method to calculate grade.
  4. Create a Calculator class with methods for add, subtract, multiply, divide.
  5. Create a Time class to display time in HH:MM:SS format.
  6. Create a Distance class and add two distances.
  7. Create a ComplexNumber class and perform addition.
  8. Create a class to swap two numbers using methods.
  9. Create a class to check prime numbers.
  10. Create a class to generate Fibonacci series.

Level 3: Inheritance
  1. Create a Vehicle class and extend it to Car and Bike.
  2. Create a Person → Student inheritance example.
  3. Create Animal → Dog, Cat classes.
  4. Create Shape → Rectangle, Circle hierarchy.
  5. Create Employee → Manager with bonus calculation.
  6. Demonstrate single inheritance with example.
  7. Demonstrate multilevel inheritance.
  8. Demonstrate hierarchical inheritance.
  9. Create a class Account → SavingsAccount, CurrentAccount.
  10. Create a base class Appliance → WashingMachine, Refrigerator.

Level 4: Polymorphism
  1. Method overloading: Create multiple add() methods.
  2. Method overriding: Override display() method in child class.
  3. Create Shape class with overridden area() methods.
  4. Create a Payment system with different payment types.
  5. Demonstrate runtime polymorphism using Animal sounds.
  6. Overload constructors in a Student class.
  7. Create a class with overloaded methods for area calculation.
  8. Override toString() method in a class.
  9. Create a Bank system with overridden interest rates.
  10. Demonstrate dynamic method dispatch.

Level 5: Abstraction
  1. Create an abstract class Shape with abstract method area().
  2. Create abstract class Vehicle and implement in child classes.
  3. Create abstract class Employee with salary calculation.
  4. Create abstract class Game and define play method.
  5. Create abstract class BankAccount with withdraw method.

Level 6: Interfaces
  1. Create an interface Printable and implement it.
  2. Create multiple interfaces and implement in one class.
  3. Create an interface Shape with area method.
  4. Create an interface Vehicle with start/stop methods.
  5. Create interface PaymentGateway and implement for UPI/Card.
  6. Demonstrate multiple inheritance using interfaces.
  7. Create a RemoteControl interface for TV.

Level 7: Encapsulation
  1. Create a class with private variables and getters/setters.
  2. Create a BankAccount with secure balance access.
  3. Create a Student class with validation for marks.
  4. Create a Employee class with salary validation.
  5. Create a User class with password security.

Level 8: Advanced OOPs Concepts
  1. Create a class demonstrating composition (Car has Engine).
  2. Create a class demonstrating aggregation (Department has Employees).
  3. Implement a singleton class.
  4. Create a class using static variables and methods.
  5. Create a class demonstrating final keyword.
  6. Create a class demonstrating object cloning.
  7. Create a class demonstrating deep copy vs shallow copy.
  8. Create a mini project: Library Management System.
  9. Create a mini project: Banking System (Deposit, Withdraw, Transfer).
  10. Create a mini project: Online Shopping Cart.
